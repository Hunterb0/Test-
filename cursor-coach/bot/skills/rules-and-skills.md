# Rules and skills

## Rules

- Project rules: `.cursor/rules/*.mdc` with frontmatter
- Prefer globs or intelligent apply; Always Apply only for truly global musts
- Keep rules short, actionable, example-backed
- Add a rule after repeated mistakes — not preemptively

## AGENTS.md

Simple root (or nested) markdown instructions when you do not need rule metadata.

## Skills and modes

- `/skill` attaches for one message
- Custom Mode (Option/Alt+Enter) keeps the skill on for a long task
- Put "how we work" in skills; put "always-true constraints" in rules

## Precedence reminder

Team Rules → Project Rules → User Rules when guidance conflicts.
